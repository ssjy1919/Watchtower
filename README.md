# Watchtower 插件功能介绍

这是一个 [Obsidian](https://obsidian.md/) 插件，专注于**文件完整性监控**与**最近打开文件**管理，帮助你在笔记库中及时发现文件变更、追踪同步状态。

> **2026-07 功能拆分说明**
>
> 本插件曾包含「插件管理」「插件更新调度器」等功能，现已拆分为独立插件 **[Plugin Manager](https://github.com/ssjy1919/PluginManager)**。
>
> - **Watchtower**（本插件）：文件监控、最近打开文件、状态栏提示
> - **Plugin Manager**：插件启停、分组、延时启动、设备类型控制、备注等
>
> 两个插件完全独立，可单独安装使用，也可同时启用。

---

## 1. 文件监控

对笔记基本数据的实时记录，确保笔记的完整性和一致性。在误操作删改笔记、多设备同步造成的文件丢失或冲突时，提供一份文件更改记录，帮助及时发现并解决问题。

当使用 Syncthing 等第三方同步方案时，切换设备不会有「同步完成」提示，需要打开同步软件查看进度。有了这份文件记录，只需在 Obsidian 内即可判断同步是否完成，无需额外打开同步工具。

**主要能力：**

- 监听文件的创建、修改、删除、重命名与打开事件
- 对比当前文件状态与上次保存的基准，展示字节增减、路径变更等差异
- 侧边栏视图展示差异文件列表，点击可跳转打开
- 支持按文件后缀排除监控范围
- 一键保存当前文件信息作为新基准（🔄 按钮或命令面板）

## 2. 最近打开文件

在文件监控侧边栏中集成「最近打开文件」表格，快速回到最近编辑过的笔记。

**主要能力：**

- 自动记录最近打开的文件及时间
- 可配置显示数量、排除特定后缀
- 可选「在新标签页打开」历史文件
- 状态栏图标右键菜单也可快速访问

---

## 3. 状态栏提示

开启后，底部状态栏显示一个可交互图标：

- 文件信息与基准一致时显示 **√**
- 存在差异时显示 **🐾** 及差异数量
- 点击展开差异列表；右键可打开最近文件

> 状态栏图标需在设置中开启，修改后**重启 Obsidian** 生效。

---

## 4. 命令面板

通过 Obsidian 命令面板（`Ctrl+P` / `Cmd+P`）快速执行：

| 命令 | 说明 |
|------|------|
| 打开侧边视图 | 打开文件监控侧边栏 |
| 保存文件信息 | 将当前文件状态保存为基准，清除差异标记 |

---

## 5. 设置项

在 **设置 → 第三方插件 → Watchtower** 中可配置：

| 设置 | 说明 |
|------|------|
| 文件监控功能 | 总开关（重启 Obsidian 生效） |
| 文件监控排除后缀 | 不参与监控的文件后缀，每行一个 |
| 在新标签页打开 | 点击历史文件时是否总是新标签页打开 |
| 历史文件排除后缀 | 最近打开列表中排除的后缀 |
| 最近历史文件数量 | 列表最大显示条数 |
| 添加底部状态栏图标 | 是否显示状态栏提示（重启 Obsidian 生效） |
